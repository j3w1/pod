# Models

The model domain has one normative home per rule:

- [Routing](models/routing.md): selection precedence, capability floor and margin, criteria, Preferred overrides, the exact pin in selection, failure holds and worker interaction (R09, R15, R19, R47, R78, R101).
- [Preferences](models/preferences.md): exact-route authority, the personal file, editing, the pin and Preferred rules, and the upgrade from 0.6.x files (R10–R13, R16, R20, R21, R77, R100).
- [Catalog and observations](models/catalog.md): the shipped registry, public observations and refresh, discovery, provenance and the joined route projection (R14, R17, R72, R102, R103).

Workspace and command contracts live in the [interface](interface.md) specification.
