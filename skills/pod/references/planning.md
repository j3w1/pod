# Planning and packets

Create a new objective worktree explicitly on branch `orca/<task-slug>`, never relying on a host default. On CE Devbox: `ce-devbox worktrees add PROJECT TASK BASE --branch orca/TASK apply`; its `agent/TASK` default stays for non-Pod work. Reuse keeps its branch. Bind the actual branch; Orca owns placement.

Adopting proposals needs direct user revision or cited project policy. Fix governance paths at intake. Explicit target selection trusts the initial snapshot; Git cannot prove authorship. Candidate-containing updates require exact-snapshot direct-user authority. Reconcile base changes before admission/effects; retain ids, history and cited text. Withdraw only genuinely gone policy. Unavailable sources hold work. Explicitly rebind unaffected proof; pending recovery stays immutable.

Map criteria, delivery and human/provider dependencies with provenance and checks. Before writes, `pod internal map` supplies seq, restatable rows, outstanding/settled attempts, undispositioned results and next actions. Patch checkpoint/report maps with `update` and next `seq`; reread on `map_stale`. Short non-assurance evidence needs check, command, result, reference; Pod binds it. A served settled assurance may use its attempt. Keep one coordinator-held active obligation. Unfinished obligations need work, external block or controlling wait; reconsider resolved waits.

Optimize time to a verified result. At transitions, dispatch ready distinct work that shortens that path. Waiting is valid; spare capacity creates no duty. Lean is never a one-worker rule. Settle shared contracts before overlapping edits.

Packets name role, served obligations, boundary, candidate, route, sources, reporting and permitted actions. Investigations need a decision and stop condition. Bind relevant digested context, never secrets or whole chats. Changed/absent sources reject; unavailable reads hold. Future outputs belong in scope, not sources. Reports join packet, admission and native attempt; Git supplies changed paths. Preserve discarded results/branches; disposition never satisfies an obligation.

Corrections use ordinary direct/delegation judgment and the current pool or pin. Briefs name failed rule, alternate entrypoints, supported older records and status/wait readers; regress related cases. Retain findings; diagnose repeats with example, hypothesis and discriminating check. Changed inputs invalidate affected proof. Orca governs handoffs.
